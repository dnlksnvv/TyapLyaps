# TyapLyaps 🎓

Интерактивный дашборд для отслеживания учебного прогресса, созданный с использованием Nuxt.js и Tailwind CSS.

## ✨ Особенности

- 🎨 **Современный дизайн** - Стеклянные эффекты и анимации в стиле Apple
- 📊 **Интерактивная статистика** - Отслеживание прогресса по предметам
- 🌊 **Водные эффекты** - Анимированные волны для визуализации прогресса
- 📱 **Адаптивный дизайн** - Работает на всех устройствах
- ⚡ **Быстрая загрузка** - Оптимизированная производительность
- 🚀 **GPU ускорение** - Максимальная производительность на мобильных устройствах
- 💾 **PWA поддержка** - Кэширование и офлайн работа

## 🏗️ Структура проекта

```
TyapLyaps/
├── frontend/          # Nuxt.js приложение
│   ├── assets/        # Стили и ресурсы
│   ├── components/    # Vue компоненты
│   ├── layouts/       # Макеты страниц
│   ├── pages/         # Страницы приложения
│   └── public/        # Статические файлы
├── backend/           # Backend API (планируется)
├── database/          # База данных (планируется)
├── docker/            # Docker конфигурация (планируется)
├── docs/              # Документация (планируется)
└── scripts/           # Скрипты автоматизации (планируется)
```

## 🚀 Технологии

- **Frontend**: Nuxt.js 3, Vue.js 3, TypeScript
- **Стили**: Tailwind CSS с кастомными компонентами
- **PWA**: Workbox для кэширования
- **Сборка**: Vite с оптимизацией
- **Производительность**: GPU ускорение, Terser минификация

## 📦 Установка

```bash
# Клонирование репозитория
git clone https://github.com/dnlksnvv/TyapLyaps.git
cd TyapLyaps

# Переход в папку frontend
cd frontend

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
```

## 🛠️ Доступные команды

```bash
# Разработка
cd frontend
npm run dev

# Сборка для продакшена
cd frontend
npm run build

# Предварительный просмотр продакшен сборки
cd frontend
npm run preview

# Запуск продакшен сервера
cd frontend
npm run start
```

## 🎯 Функциональность

- **Дашборд** - Обзор всех предметов и статистики
- **Предметы** - Детальная информация по каждому предмету
- **Прогресс** - Визуализация выполнения лабораторных работ
- **Статистика** - Анализ учебного прогресса
- **Настройки** - Персонализация интерфейса

## 🎨 Дизайн

Проект использует современный дизайн с:
- Стеклянными эффектами (glassmorphism)
- Параллакс анимациями
- Водными эффектами для прогресса
- Адаптивной сеткой
- Темной темой

## ⚡ Оптимизация производительности

- **GPU ускорение** - Все элементы используют GPU рендеринг
- **PWA кэширование** - Страницы кэшируются на 30 секунд
- **Статические ресурсы** - Кэшируются на 7 дней
- **Минификация** - Terser с агрессивными настройками
- **Tree-shaking** - Удаление неиспользуемого кода
- **CSS оптимизация** - PurgeCSS для удаления неиспользуемых стилей
- **Мобильная оптимизация** - Отключение анимаций на слабых устройствах

## 📱 Адаптивность

- **Desktop** - Полнофункциональный интерфейс
- **Tablet** - Оптимизированная версия
- **Mobile** - Мобильное меню и компактный дизайн

## 🌳 Ветки и деплой

- **`main`** - Стабильная версия (production)
- **`develop`** - Ветка разработки
- **`production`** - Ветка для деплоя

### Workflow:
1. Разработка в ветке `develop`
2. Тестирование в ветке `production`
3. Слияние в `main` для релиза
