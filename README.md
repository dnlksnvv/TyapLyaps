# TyapLyaps 🎓

Интерактивный дашборд для отслеживания учебного прогресса, созданный с использованием Nuxt.js и Tailwind CSS.

## ✨ Особенности

- 🎨 **Современный дизайн** - Стеклянные эффекты и анимации в стиле Apple
- 📊 **Интерактивная статистика** - Отслеживание прогресса по предметам
- 🌊 **Водные эффекты** - Анимированные волны для визуализации прогресса
- 📱 **Адаптивный дизайн** - Работает на всех устройствах
- ⚡ **Быстрая загрузка** - Оптимизированная производительность

## 🚀 Технологии

- **Frontend**: Nuxt.js 3, Vue.js 3, TypeScript
- **Стили**: Tailwind CSS с кастомными компонентами
- **Состояние**: Pinia
- **Сборка**: Vite

## 📦 Установка

```bash
# Клонирование репозитория
git clone https://github.com/dnlksnvv/TyapLyaps.git
cd TyapLyaps

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
```

## 🛠️ Доступные команды

```bash
# Разработка
npm run dev

# Сборка для продакшена
npm run build

# Предварительный просмотр продакшен сборки
npm run preview

# Подготовка Nuxt
npm run postinstall
```

## 🎯 Функциональность

- **Дашборд** - Обзор всех предметов и статистики
- **Предметы** - Детальная информация по каждому предмету
- **Прогресс** - Визуализация выполнения лабораторных работ
- **Статистика** - Анализ учебного прогресса
- **Настройки** - Персонализация интерфейса

## 🎨 Дизайн

Проект использует современный дизайн с:
- Стеклянными эффектами (glassmorphism)
- Параллакс анимациями
- Водными эффектами для прогресса
- Адаптивной сеткой
- Темной темой

## 📱 Адаптивность

- **Desktop** - Полнофункциональный интерфейс
- **Tablet** - Оптимизированная версия
- **Mobile** - Мобильное меню и компактный дизайн
