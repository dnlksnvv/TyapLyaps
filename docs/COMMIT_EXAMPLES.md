## 🚀 **Быстрые команды**

```bash
# Создать ветку для фичи
git checkout -b feature/new-feature

# Создать ветку для багфикса  
git checkout -b fix/bug-description

# Коммит новой фичи
git add .
git commit -m "feat: добавить новую функцию"

# Коммит исправления
git add .
git commit -m "fix: исправить баг"
```

## 💡 **Советы**

- **feat** - когда добавляете что-то новое
- **fix** - когда исправляете что-то сломанное
- Используйте настоящее время ("добавить", не "добавлено")
- Будьте краткими но понятными
- Не ставьте точку в конце
