# 📝 Правила коммитов для TyapLyaps

## 🎯 Простые правила

Используем только **2 типа** коммитов для простоты.

## 📋 Формат коммита

```
<type>: <description>
```

## 🏷️ Типы коммитов

### ✨ **feat** - Новая функциональность
```bash
feat: добавить авторизацию пользователей
feat: добавить график прогресса
feat: добавить темную тему
feat: добавить мобильное меню
```

### 🐛 **fix** - Исправление багов
```bash
fix: исправить ошибку загрузки данных
fix: исправить отображение на мобильных
fix: исправить валидацию формы
fix: исправить кэширование
```

## 📝 Примеры коммитов

### ✅ **Правильно:**
```bash
feat: добавить авторизацию пользователей
feat: добавить график прогресса
fix: исправить ошибку загрузки данных
fix: исправить отображение на мобильных
```

### ❌ **Неправильно:**
```bash
fix bug
update
changes
work in progress
test
```

## 📖 Правила описания

- Используйте **настоящее время** ("добавить", не "добавлено")
- Используйте **строчные буквы** в начале
- **Не ставьте точку** в конце
- Будьте **краткими** но **описательными**

## 🔄 Workflow с ветками

### 1. **Создание ветки для фичи:**
```bash
git checkout develop
git pull origin develop
git checkout -b feature/user-authentication
```

### 2. **Коммиты в ветке фичи:**
```bash
git add .
git commit -m "feat: добавить форму входа"
git commit -m "feat: добавить валидацию полей"
git commit -m "fix: исправить ошибку валидации"
```

### 3. **Создание Pull Request:**
```bash
git push origin feature/user-authentication
# Создать PR в GitHub: feature/user-authentication → develop
```

### 4. **Создание ветки для багфикса:**
```bash
git checkout develop
git pull origin develop
git checkout -b fix/dashboard-mobile-layout
```
